# PSX Intelligence V3.2 — Functional Tabs + Global Search

## Android improvements
- Global `Search` button in the top bar, available from every main screen.
- Search results are clickable and open the stock terminal directly.
- Search is also available from Home quick actions.
- Intelligence tabs use horizontal scrolling so labels no longer wrap awkwardly.
- Technicals performs live historical calculations.
- Fundamentals fetches the official PSX company page.
- Structure now performs historical close-range/trend analysis instead of static text.
- Wyckoff now performs conservative historical range/event analysis instead of static education text.
- AI tab builds a live evidence-first bull/bear/confirmation/invalidation brief.
- `Speak` button reads the currently selected intelligence analysis aloud with Android TTS.
- Intelligence Lab cards are clickable and launch stock search.
- Visible branding updated to V3.2.

## Accuracy boundaries
The public EOD timeseries is used for close-history calculations. True OHLCV-dependent claims remain
unconfirmed until genuine OHLCV is available through the V3 backend. The app never promotes a close-only
Spring/UT-style candidate to a confirmed Wyckoff event.
